## 🧩 About

**Abiotic Factor Companion** is a curated list of Abiotic Factor open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, sector marker
- **Quality-of-Life Helpers** — crafting catalog, loot organizer, overlay notes

Based on publicly available community tools and overlay helpers.
